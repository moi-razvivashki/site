Частые вопросы

Как я получу набор?

Сразу после оплаты бот нашего сообщества ВКонтакте автоматически пришлёт PDF в сообщения — в любое время суток. Купленные файлы можно получить ещё раз кнопкой «Мои покупки».

Можно печатать на чёрно-белом принтере?

Да. Задания нарисованы чёткими линиями и хорошо выглядят и в цвете, и в чёрно-белом.

Для какого возраста задания?

«Зимние развивашки» — для 3–4 лет, новогодний набор — для 4–6 лет, «Зимняя подготовка к школе» — для 6–7 лет, «Развивашки для мальчиков» и «Развивашки для девочек» — для 4–6 лет. Если ребёнок между возрастами, начните с младшего набора.

Можно ли использовать в детском саду или на занятиях?

Обычный набор — для семьи. Для воспитателей, логопедов и детских центров есть версия с правом печати на группу — напишите нам.

Как оплатить?
